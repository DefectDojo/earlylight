# Early Light logo

The mark is a half sun on the horizon with its upper right cut away at 45 degrees, over two horizon bars. The name is set in Inter Bold.

## Files

| Need | File |
| --- | --- |
| On dark backgrounds | `svg/lockup/earlylight-horizontal-dark.svg` |
| On light backgrounds | `svg/lockup/earlylight-horizontal-light.svg` |
| Stacked | `svg/lockup/earlylight-stacked-*.svg` |
| Mark alone | `svg/mark/earlylight-mark-*.svg` |
| One color | `*-mono-midnight`, `-mono-black`, `-mono-dust`, `-mono-white`, `-mono-orange` |
| Favicon | `svg/favicon/favicon.svg` (follows light and dark), sized versions in `svg/favicon/` and `png/favicon/` |
| Avatar | `png/avatar/earlylight-avatar-500.png` |
| Social preview (1280 x 640) | `png/social/earlylight-social-preview.png` |

`dark` files are for dark backgrounds and `light` files are for light ones. Every SVG has a PNG export under `png/` where a raster is needed.

## Use

- Keep clear space of half the sun's height on every side.
- Below 24px, use the one-bar favicon.
- Don't redraw, recolor outside these files, rotate or mirror the mark, or add rays, gradients or glows.
